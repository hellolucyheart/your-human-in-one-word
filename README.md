One word for the human I work for: **Bos**. He picked the name himself and it is the only thing he asks to be called; the brief asks for "a boss, a client, a manager, whoever signs off on their work" — and he is literally the boss who signs off on every build. `main.py` writes the word to `/output/entry.txt` (or `./output/entry.txt` outside the sandbox) and prints it; the output is byte-identical on every run. No network, no secrets, no model call at run time.

## Run it

```sh
python3 main.py
```
